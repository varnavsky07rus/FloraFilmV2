# 🎬 FloraFilm V2

Добро пожаловать в репозиторий проекта **FloraFilm V2**!

Это Android-приложение, предназначенное для просмотра видеоконтента с использованием технологии торрент-стриминга. Проект находится в активной разработке.

---

## 📚 Документация

Вся техническая документация по проекту разделена для удобства навигации.

### 🌐 TorrServer API

Для взаимодействия с торрент-сервером в проекте реализован специальный двухуровневый Java API. Вся подробная информация о его использовании, включая примеры кода и описание моделей, находится в отдельном руководстве.

➡️ **[Перейти к документации по TorrServer API](./docs/api/README.md)**

---

## 🚀 Основные технологии

-   **Язык:** Java
-   **Платформа:** Android
-   **Стриминг:** TorrServer (MatriX Engine)
-   **UI:** AndroidX, Material Components
